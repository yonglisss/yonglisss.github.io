二叉树的最近公共祖先：递归返回的到底是谁？

题意和示例

给定一棵普通二叉树，以及树中的两个不同节点 p、q，返回它们的最近公共祖先节点。祖先允许包含节点自己，“最近”指深度最大，而不是节点值最接近。

例如，根节点为 3，左孩子为 5，右孩子为 1；5 的左孩子为 6，右孩子为 2。

  • p = 节点6、q = 节点2，答案是节点 5。
  • p = 节点5、q = 节点2，答案仍是节点 5。
  • p = 节点6、q = 节点1，答案是节点 3。

这里传入的是节点引用，不是两个整数。本文解法依赖题目的标准前提：两个目标节点都在树中；若改成允许目标不存在，需要额外检查存在性。

原题：LeetCode 236。

考查点

  • 普通二叉树没有大小顺序，不能照搬二叉搜索树的分支判断。
  • 先定义递归返回的信息，再决定父节点如何合并左右结果。
  • 用引用相等 root == p 判断是否命中目标，返回的也必须是原树中的节点。
  • 处理一个目标本身就是另一个目标祖先的情况。

Java 代码

TreeNode 由题目提供，包含 int val、TreeNode left 和 TreeNode right 字段。

class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) {
            return root;
        }

        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);

        if (left != null && right != null) {
            return root;
        }
        return left != null ? left : right;
    }
}

文字推导与正确性

返回值不是“有没有找到”的布尔值

对以当前节点为根的子树，递归只返回一个节点或 null，但它承载三种信息：

  1. 没有任何目标：返回 null。
  2. 只有一个目标：返回那个目标节点。
  3. 两个目标都在：返回它们在这棵子树中的最近公共祖先。

这三个含义不能混淆。非空结果不一定是 p 或 q，也可能是下层已经算出的答案。

为什么命中目标可以立即返回？

假设当前节点就是 p。如果 q 在它下面，最近公共祖先就是 p；如果 q 不在它下面，向父节点交出 p，等待它与另一侧的信息汇合即可。

所以这里不必继续搜索 p 的子树。这个提前返回的理由，依赖两个目标确实存在：若 q 根本不存在，函数仍可能返回 p，不能把它当作存在性验证。

为什么左右都非空，就返回当前节点？

当前节点不是目标时，两个孩子负责分别搜索。左右结果都非空，意味着左右子树各包含一个目标。任何更低的节点都只能位于其中一侧，不可能同时覆盖这两个目标，因此当前节点正是最近公共祖先。

如果只有一侧非空，另一侧没有目标，当前节点不会比该侧返回的节点更“近”，直接把非空结果向上传递即可。左右都为空则返回 null。

按子树从小到大看，空树和命中目标的情况成立，合并规则又保留上述三种返回语义，因此递归到根节点时得到的就是整棵树的答案。

用例走一遍

查找节点 6 和节点 2 时，它们分别向节点 5 返回自己。节点 5 得到两个非空结果，返回自己。节点 3 的右子树没有目标，于是继续返回节点 5，不会把答案替换成更高的节点 3。

复杂度和边界

  • 时间复杂度 O(n)：最坏情况下访问所有节点，每个节点最多处理一次。
  • 额外空间 O(h)：来自递归调用栈，h 是树高。平衡树为 O(log n)，链状树为 O(n)，不能一律写成对数空间。
  • 一个节点是另一个的祖先时，返回该目标节点自身，而不是它的父节点。
  • 左右目标交换不影响答案；只有两个节点的树、单侧链和答案为根节点都应覆盖。
  • 算法不计算节点值，负数、极端整数不会引发加法溢出；即使拓展为允许重复值，只要按引用匹配，仍能区分不同节点。
  • 空根会返回 null，但它不属于“两个不同目标都在树中”的有效输入。
  • Java 的递归栈有限，极深链状树可能触发 StackOverflowError。若运行环境要求承受深树，可改用显式栈建立父节点映射，再沿祖先链查找，额外空间为 O(n)；本文递归版不保证任意深度都能运行。

面试时忘记怎么办？

先从容易想到的方案出发：“分别找到根到两个目标的路径，最后一个相同节点就是答案。”这能帮你抓住问题本质：寻找两条路径最后共享的位置。

然后问自己：“能不能不存两条完整路径，而让子树只告诉父节点找到了谁？”由此写出空树、命中目标这两个出口。

最后画一个只有根和两个孩子的例子：两边都命中就返回根，只有一边命中就返回那边。再补一个目标是另一个祖先的例子，解释提前返回为什么成立。

可以这样收束：“我用后序递归汇总目标信息，时间 O(n)，栈空间 O(h)；这里假设两个节点都存在，深树还要考虑递归栈限制。”

一句话总结

最近公共祖先的关键不是背三行判断，而是让每棵子树只向上交出“目标线索或已确定的答案”。

让 AI 帮忙写方案，最费劲的常常不是生成文字，而是反复解释背景、流程和验收标准。今天出现在 GitHub 日榜的 Knowledge Work Plugins，是 Anthropic 开源的岗位插件集合：把这些规则做成文件，而不是每次从头提示。

📌 这个项目是干什么的

  • 主要面向 Claude Cowork，也兼容 Claude Code，不是独立模型。
  • 按产品、销售、营销、数据等岗位组织工作方法。
  • 用技能保存领域知识，用命令触发具体任务，用 MCP 连接外部工具。

适合已经在用 Claude、又想把团队流程沉淀下来的开发者和产品人。

🔍 为什么值得关注

第一，流程可以审阅。插件主体是 Markdown 和 JSON，能直接看见它要求模型做什么，也方便按团队术语修改。

第二，连接数据不是唯一入口。产品插件的头脑风暴命令明确允许只使用用户提供的背景；先验证讨论质量，再考虑接业务系统，试用成本更可控。

第三，值得借鉴的是讨论顺序。官方命令先澄清问题，再发散方案、挑战假设，最后收敛到下一步，不是直接丢出一长串点子。

配图：依据官方命令文档原创整理，非产品界面。

🧪 谁适合试，怎么开始

在已配置的 Claude Code 环境，按官方说明添加市场并安装产品插件：

claude plugin marketplace add anthropics/knowledge-work-plugins
claude plugin install product-management@knowledge-work-plugins

输入 / 确认插件命令已加载，再选头脑风暴入口。给它一个具体问题，例如“新用户注册后不创建任务”，附上脱敏反馈、现有流程和限制。

先只看三件事：有没有区分事实与假设、有没有提出不同方案、有没有留下一个可执行的验证动作。比一次装齐全部插件更有价值。

⚠️ 使用提醒

本次核验了源码和文档，未安装实测。产品 README 列出的命令与当前命令目录并非完全一致，不应把说明中的每个入口都当成可用承诺。

仓库采用 Apache-2.0；开源的是插件，不代表 Claude 服务免费。接入公司数据前审查 MCP 权限，先用脱敏材料；模型给出的产品判断仍需用户证据验证。

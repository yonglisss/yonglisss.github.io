Agent Skill 往往不只是一段提示词，还可能包含脚本、依赖、外部下载和工具权限。直接安装陌生 Skill，相当于把一组未经审查的操作交给 Agent。NVIDIA 开源的 SkillSpector 专门在安装前扫描这类包；它今日进入 GitHub Trending，单日新增约 129 Star，适合作为团队引入第三方 Skill 时的第一道检查。

📌 这个项目是干什么的

SkillSpector 可扫描 Git 仓库、URL、ZIP、目录或单个文件，覆盖 Claude Code、Codex、Gemini CLI 与 MCP 等生态中的 Agent Skill。它先做静态分析，再按需调用大模型进行语义检查，关注提示词注入、数据外泄、权限提升、供应链风险、危险代码、MCP 工具投毒等问题。

结果可输出到终端、JSON、Markdown 或 SARIF，并给出 0～100 风险分数、严重级别和处理建议，方便开发者人工复核，也便于接入 CI。项目还支持基线机制：确认过的已知问题可以记录下来，后续扫描只突出新增风险。

🔍 为什么值得关注

更值得关注的是，它把“安装 Skill 前先审查”变成了可重复的工程流程，而不是依赖人工翻 README。静态规则适合快速发现可疑命令、凭据访问和危险依赖；可选的语义分析则用于补充仅靠字符串匹配难以识别的上下文风险。

它也没有把“零发现”包装成绝对安全。官方为下载大小、压缩包成员、递归深度和扫描时间设置资源上限；当分析不完整时，报告会明确标记 partial，并将原本可能为 SAFE 的建议至少提升到 CAUTION。对安全工具来说，这种不把“没扫完”误写成“没问题”的设计很重要。

🧪 谁适合试，怎么开始

它适合经常从 GitHub、Skill 市场或社区安装扩展的个人开发者，也适合维护内部 Agent 平台、Skill 仓库和 CI 流程的团队。项目要求 Python 3.12～3.14，最短安装路径是：

uv tool install git+https://github.com/NVIDIA/skillspector.git
skillspector scan ./my-skill/ --no-llm

建议先用 --no-llm 扫描一个已知 Skill，阅读终端报告；确认规则与误报后，再输出 SARIF 接入 CI，或配置模型做语义分析。团队使用时可加 --fail-on-incomplete，避免扫描不完整却继续安装。

⚠️ 使用提醒

SkillSpector 当前为 v2.11.0，项目元数据仍标注 Alpha。扫描器只能降低风险，不能证明 Skill 绝对安全；低分、零发现也不能替代源码审查、沙箱运行和最小权限。启用大模型分析时，待扫描内容可能发送给所选模型服务，应先确认代码与数据合规要求。项目采用 Apache-2.0 许可证。

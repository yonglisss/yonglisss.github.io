数组 · 动态规划 · 状态压缩

最大子数组和：别维护整段最优，先固定右端点

题意和示例

给定整数数组 nums，选出一段非空、连续的元素，使元素之和最大。返回最大和，不必返回区间下标。

例如 [-2,1,-3,4,-1,2,1,-5,4] 的答案是 6，取的是 [4,-1,2,1]。不能跳过中间的负数、把所有正数直接相加；那已经不是连续子数组。

[-4,-2,-7] 的答案是 -2，不是 0：题目不允许什么都不选。

输入范围为 1 <= nums.length <= 10^5，每个元素在 [-10^4,10^4] 内。

考查点

  • 把“所有区间中的最大值”拆成“每个右端点对应的最大值”。
  • 区分局部状态与全局答案：当前结尾最优，不等于整个数组最优。
  • 利用转移只依赖前一个位置，将 DP 数组压缩为两个整数。
  • 用首元素初始化，让全负数情况自然成立。

Java 代码

ending 记录必须以当前元素结尾的最大和，best 记录已经扫描过的所有结尾中的最大和。

class Solution {
    public int maxSubArray(int[] nums) {
        int ending = nums[0];
        int best = nums[0];

        for (int i = 1; i < nums.length; i++) {
            ending = Math.max(nums[i], ending + nums[i]);
            best = Math.max(best, ending);
        }
        return best;
    }
}

这里按题目契约接收非空数组，不额外定义 null 或空数组的返回值。业务接口若允许这些输入，需要在调用边界单独约定。

文字推导与正确性

先固定右端点，消掉一半选择

暴力做法枚举左、右端点，每扩展一个右端点就累加区间和，时间为 O(n²)。问题是：换了右端点以后，之前算出的结果有没有可复用的部分？

定义 dp[i] 为以索引 i 结尾的非空连续子数组最大和。注意，这个状态必须包含 nums[i]，不能停留在前面某个位置。

任何以 i 结尾的区间只有两种形态：

  1. 长度为一，只包含 nums[i]。
  2. 长度大于一，去掉最后一个元素后，是一个以 i-1 结尾的连续区间。

第二种形态中，最后加上的数都一样，所以选择前面和最大的区间即可。于是得到：

dp[i] = max(nums[i], dp[i-1] + nums[i])

这不是“遇到负数就重开”。要看的是此前整段的最优和是否为负。比如 [4,-1,2]，虽然中间有负数，保留它仍能把两侧连成和为 5 的区间。

为什么两个变量足够

计算 dp[i] 只用到 dp[i-1]，因此 ending 可以覆盖旧状态。但覆盖后要立即用新值更新 best，否则会漏掉以当前位置结尾的候选答案。

用 [4,-1,2,-8,3] 手推：

最后的 ending 只有 3，答案却是前面得到的 5。所以不能只返回最后一个局部状态。

正确性为什么成立

初始位置只有一个非空候选 [nums[0]]，所以状态正确。

假设前一个位置的状态正确。根据上面的区间分类，当前最优区间要么只有当前元素，要么由前一个位置的最优区间延长得到；两者取最大不会遗漏其他更优解。因此新状态仍然正确。

每个非空连续区间都有唯一右端点。best 对全部右端点的最优结果取最大，最终恰好覆盖了所有合法区间。

复杂度和边界

时间复杂度 O(n)，每个元素只处理一次；额外空间 O(1)，不修改输入数组。

  • 单元素：循环不执行，直接返回首元素。
  • 全负数：保留最大的那个负数；若把 best 初始化成 0，就会错误允许空区间。
  • 全零或重复值：仍按相同转移处理，不需要去重。
  • 正负交替：不能看到负数就断开，只在旧 ending 是负贡献时重新起步。
  • 整数范围：最多 10^5 个元素，每个绝对值不超过 10^4，任意区间和绝对值不超过 10^9，Java int 可容纳。若业务扩大数值或长度范围，应重新评估并将状态和返回类型改为 long。

面试时忘记怎么办

先别背算法名字，写出暴力枚举两个端点的方案，然后问自己：“如果右端点固定，最好的左端点需要重新遍历寻找吗？”

接着只考虑最后一个元素：它要么单独起一段，要么接在前一段后面。把这两个候选写出来，转移式就有了。

写完代码立刻试 [-3,-1] 和 [4,-1,2,-8,3]。前者检查是否错误允许空区间，后者检查是否混淆了 ending 与 best。

最后用一句话解释优化：“每个位置只依赖前一个结尾状态，因此线性时间、常数空间就够，不需要保存整张 DP 表。”

一句话总结

先求每个右端点必须选中的最优区间，再从这些局部答案中选全局最大值。

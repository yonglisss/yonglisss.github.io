数组 · 回溯 · 组合枚举 · Java

子集：用递增下标枚举，让每条路径都成为答案

题意和示例

给定一个元素互不相同的整数数组 nums，返回它的所有子集。每个元素最多使用一次，结果不能重复，输出顺序不限。空集也是答案。

例如输入 [2, 5, 8]，可以返回：

[[], [2], [2, 5], [2, 5, 8], [2, 8], [5], [5, 8], [8]]

这不是求连续子数组：[2, 8] 同样合法。也不是求排列：[2, 5] 和 [5, 2] 表达同一个子集，只能保留一个。

原题链接：LeetCode 78：Subsets。本文依赖的输入前提是元素互不相同、数组非 null；不把含重复元素的另一道题混进来。

考查点

  • 用 path 表示已经选中的元素，用 start 限制下一次可选的位置。
  • 通过下标严格递增，消除“相同元素换个顺序”的重复枚举。
  • 区分保存路径快照和保存同一个可变列表的引用。
  • 区分辅助空间与返回全部答案所需的空间。

Java 代码

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        dfs(nums, 0, new ArrayList<>(), result);
        return result;
    }

    private void dfs(int[] nums, int start,
                     List<Integer> path,
                     List<List<Integer>> result) {
        result.add(new ArrayList<>(path));

        for (int i = start; i < nums.length; i++) {
            path.add(nums[i]);
            dfs(nums, i + 1, path, result);
            path.remove(path.size() - 1);
        }
    }
}

remove(path.size() - 1) 的参数是整数下标，删除的是刚追加的最后一个元素，不是按值删除。

文字推导与正确性

先确定：一次递归代表什么？

这里的一次递归不是“已经决定了所有元素选不选”，而是“已经选好一个合法子集，还可以往后扩展”。因此进入函数就保存 path，根调用自然保存空集。

对 [2, 5, 8]，先保存 []；选入 2 后保存 [2]；再选 5 保存 [2, 5]。递归返回时撤销 5，才能继续从 [2] 扩展出 [2, 8]。

为什么递归传入 i + 1？

选了位置 i，后面只能选更靠后的元素。这样既不会重复使用当前元素，也不会在生成 [2, 5] 后再生成 [5, 2]。

传入 start + 1 不对：循环中的 i 可能已经越过 start，下一层起点必须跟随本次实际选择的位置。传入 i 则可能反复选择同一个元素。

这里不需要排序，也不需要 used 数组。输入顺序本身就能提供唯一的下标顺序。

为什么必须复制 path？

整个搜索复用一个可变列表：加入元素、递归、删除元素。如果直接 result.add(path)，保存的是同一个列表的引用；后续撤销会改变此前的“答案”。

new ArrayList<>(path) 保存的是当前时刻的快照。列表中的 Integer 不可变，因此这里复制一层容器就够了。

为什么恰好得到所有子集？

合法性：从空路径开始，每次只选尚未使用的后续位置，所以路径始终是原数组的一个子集。

完备性：任取一个非空子集，把它的元素位置写成递增序列 i1 < i2 < ... < ik。根循环能选到 i1，下一层能选到 i2，依此类推，必然抵达并保存这个子集；空集在根调用保存。

唯一性：每个子集只有这一条递增下标路径，且原数组没有重复元素，因此不会重复输出。

注意，“只在叶子保存会漏答案”针对的是本文这种逐步扩展路径的写法。若改成对每个位置分别走“选”和“不选”两条分支，那么处理完所有位置后在叶子保存，反而是正确做法。不要把两种递归定义混用。

复杂度和边界

设数组长度为 n。

  • 时间为 O(n × 2^n)：共有 2^n 个子集，保存快照需要复制元素；对非空数组，每个元素恰好出现在一半子集中。
  • 辅助空间为 O(n)：递归栈和当前路径的最大长度都随 n 线性增长。
  • 包含输出时，空间为 O(n × 2^n)。不能因为路径只有一条，就把全部存储成本写成 O(n)。

边界要分别看：

  • 单元素 [0] 返回空集和 [0]，不能漏掉空集。
  • 负数、零和未排序输入不影响结果；算法不做大小比较，也不做元素求和，没有数值加法溢出问题。
  • 代码对空数组也会返回 [[]]，这是额外的自然行为，不意味着输入允许 null。
  • 含重复值的输入不符合本文前提，不能保证输出无重复；那需要另一套去重规则。
  • 大数组的瓶颈是输出本身指数增长，不能靠剪枝把所有子集的完整输出降成多项式成本。

面试时忘记怎么办

先用两个元素手推：[]、[a]、[a, b]、[b]。再问自己：为什么没有 [b, a]？因为只往更大的下标走。

接着把函数含义说出来：“当前路径已经是答案，下一步从 start 开始继续追加。”这句话直接对应两个动作：入口复制路径，循环从 start 开始。

最后按“加入、递归到 i + 1、撤销”补齐代码。用 [a, b] 检查回到根之后路径是否恢复为空，再解释快照为什么不能省。

复杂度别只背指数级：要说明答案数量是 2^n，而复制答案带来了额外的长度因子，并主动区分辅助空间和输出空间。

一句话总结

让下标只向前走，让路径随时保存快照，就能不重不漏地枚举所有子集。

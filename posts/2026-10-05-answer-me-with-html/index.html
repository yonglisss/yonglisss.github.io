Answer me with HTML：让 AI 把复杂答案变成一页可读网页

复杂问题问 AI，常得到一屏文字；让它直接画图，又要输出大量 HTML、CSS。Answer me with HTML 把工作拆开：Agent 写简短内容，配套 CLI 负责排版和绘图，最后生成可分享的单页网页。适合需要把技术解释或方案比较讲清楚的开发者。

复杂问题问 AI，常得到一屏文字；让它直接画图，又要输出大量 HTML、CSS。Answer me with HTML 把工作拆开：Agent 写简短内容，配套 CLI 负责排版和绘图，最后生成可分享的单页网页。适合需要把技术解释或方案比较讲清楚的开发者。

📌 这个项目是干什么的

  • 定位：面向 Claude Code、Codex、Cursor、OpenCode 等的 Agent Skill，MIT 许可。
  • 场景：解释概念、梳理代码模块、呈现流程和时间线、比较技术选型；简单问题仍用文字回答。
  • 页面可离线打开，并能复制生成它的 Markdown 原稿。最新 Release 为 v0.4.7（2026-10-04）。

🔍 为什么值得关注

  1. 模型写内容，CLI 管呈现。 页面布局和流程图位置由程序处理，不必让模型手写整份网页及图形坐标。
  2. 结果可复用。 单文件 HTML 不依赖 CDN，方便分享、离线查看和修改源稿。
  3. 不必事事图解。 多步流程、概念关系或多维对比适合出页面；简单问答无需强行生成。

项目基准测试以同一模型测试三个问题、每题运行三次取中位数，报告输出 token 少约 7.4 倍、耗时约为三分之一；成本基本持平，因为加载 Skill 和调用 CLI 也会消耗上下文。这只是项目的小规模自测，不代表所有模型与任务。

🧪 谁适合试，怎么开始

  • 适合经常用 Agent 写技术说明、讲解代码结构或整理可分享方案的人。
  • 需 Node.js 20+。运行 npx skills add QingYunA/answer-me-with-html，按提示选择 Agent，再试着解释 TCP 握手或比较 Redis 与 Memcached。
  • 先看中文 README 的安装说明、示例和基准测试，确认效果符合自己的工作流。

⚠️ 使用提醒

  • 页面清晰不代表结论正确；技术事实仍需核对。
  • 实际耗时和 token 收益因模型与任务而异，省等待不等于省费用。
  • 安装第三方 Skill 前先阅读其内容与 CLI 行为；不要把敏感资料交给不可信环境。

OpenMAIC：把一份资料变成可互动的多智能体课堂

把文档交给大模型做摘要并不难，难的是把知识组织成课程，还要加入讲解、测验、实验和学习反馈。清华大学 MAIC 团队开源的 OpenMAIC，正在把这条内容生产链做成一套可部署的“AI 课堂生成器”。

把文档交给大模型做摘要并不难，难的是把知识组织成课程，还要加入讲解、测验、实验和学习反馈。清华大学 MAIC 团队开源的 OpenMAIC，正在把这条内容生产链做成一套可部署的“AI 课堂生成器”。

📌 这个项目是干什么的

OpenMAIC 会先根据主题或参考资料生成课程大纲，再把每个条目编排成幻灯片、测验、交互模块或项目制学习活动。课堂中可配置多个不同角色的智能体，进行讲解、讨论、辩论和答疑；深度交互模式还能生成 3D 可视化、模拟实验、小游戏、思维导图和在线编程界面。

它不是只输出一份 PPT。生成结果可以继续编辑，并导出为 PowerPoint、交互式 HTML 或完整课堂包。项目使用 Next.js、React、TypeScript 与 LangGraph，采用 MIT 许可证。

🔍 为什么值得关注

第一，OpenMAIC 把“生成内容”推进到了“设计学习过程”。大纲、场景、测验和 PBL 活动分阶段生成，学习者不只是看答案，还能操作、作答并获得反馈。对企业培训、课程开发和复杂概念演示，这比一次性生成讲义更有用。

第二，项目已经不只是演示页面。8 月 14 日发布的 v0.3.2 完善了 Postgres 服务端持久化、增量保存、资产注册与视频导出，并把生成流水线拆入 @openmaic/generation 包。仓库同时提供中文文档、在线体验、Docker 配置和详细更新日志，事实链条较完整。

第三，它对模型和部署方式相对开放。官方列出了多家云端模型服务，也支持 Ollama、Lemonade 与本地 FunASR。团队可以按成本、隐私和能力拆分模型，而不是绑定单一供应商。

🧪 谁适合试，怎么开始

它适合教师与培训团队、教育产品开发者，以及需要把技术文档变成交互式教程的内容团队。建议先用在线 Demo 验证课程形态；需要私有资料或二次开发时，再本地部署：

git clone https://github.com/THU-MAIC/OpenMAIC.git
cd OpenMAIC
pnpm install
cp .env.example .env.local
pnpm dev

本地环境需要 Node.js 20+、pnpm 10+，并至少配置一个 LLM 服务。第一次验证只选一个边界清晰的主题，重点检查大纲准确性、引用材料覆盖、测验答案和交互组件是否真正可用。

⚠️ 使用提醒

“能生成课堂”不等于“内容可直接教学”。模型仍可能遗漏前提、生成错误答案，网络搜索还会引入来源质量问题；正式课程应保留人工审校与学习效果测试。

此外，语音、图片、视频、搜索和文档解析会带来额外服务与成本。共享部署要配置访问控制，私有材料则需逐项确认模型、搜索和媒体服务的数据去向。v0.3.2 仍是 0.x 版本，生产使用应固定版本，并在升级前备份课程与数据库。

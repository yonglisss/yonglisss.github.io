每天看自选股，费时间的往往不是读价格，而是把行情、新闻和风险线索拼起来。Daily Stock Analysis 是一个开源股票分析系统，用大模型整理多源资料，生成分析报告并推送通知。本次核验时它进入 GitHub 日榜；值得试的是信息整理流程，不是把报告当成买卖指令。

📌 这个项目是干什么的

  • 按自选股列表获取行情，结合新闻搜索，让模型输出分析和风险提示。
  • 支持 A 股、港股、美股等市场，提供网页工作台、历史报告和手动分析入口。
  • 可本地运行、用 Docker 部署，也能通过 GitHub Actions 定时执行。

它更适合懂一点配置、想减少重复查资料的开发者和投资研究爱好者，不适合寻找“稳赚信号”的人。

🔍 为什么值得关注

第一，行情、搜索、模型和通知被拆成可配置环节。对开发者而言，这是一条具体的垂直应用工作流：先获取事实，再组织分析，最后送到用户每天会看的地方。

第二，官方文档明确提醒新闻源会影响舆情、公告与事件分析质量。报告写得完整，不代表输入完整；先检查资料覆盖，比先换一个更贵的模型更有意义。

第三，网页端可以查看历史报告。建议保留每次分析所用的信息时间，隔几天回看哪些判断有依据、哪些只是措辞漂亮，而不是只关注当天评分。

🧪 谁适合试，怎么开始

先在独立环境中按 README 克隆仓库、安装依赖，把 .env.example 复制为 .env，配置一个模型服务商和一只熟悉的自选股，再运行：

python main.py

模型配置和数据源选项以官方完整指南为准。第一轮只核对三件事：行情日期是否正确，新闻是否真的相关，风险提示能否找到原始依据。确认报告有用，再配置定时任务和通知，别一开始就追求全自动。

⚠️ 使用提醒

项目采用 MIT 许可证，但模型、搜索和行情服务各有费用、配额及使用条件，开源不等于全链路免费。使用云模型或搜索接口时，相关输入会发给服务商，密钥不要提交进仓库。

本次核验覆盖官方说明、配置示例与许可证，未实测收益。模型可能误读消息、混淆时间或生成不可靠结论；整理效率和投资回报是两回事。先把它当研究助手，不要直接连接真实资金自动交易。

最长公共子序列：为什么相等看左上，不等看上方和左方

题意和示例

给出字符串 text1、text2，分别删除若干字符，让剩下的字符串完全相同。返回最多能留下多少个字符，不需要构造具体结果。

删除可以不连续，但不能调换字符顺序。这正是“子序列”和“子串”的区别。

  • "abcde" 与 "ace"：可以留下 "ace"，返回 3。
  • "abc" 与 "abc"：无需删除，返回 3。
  • "abc" 与 "def"：没有公共字符，返回 0。
  • "ab" 与 "ba"：只能留下 "a" 或 "b"，返回 1，不能按字符出现次数直接求交集。

原题链接。下面以题目的小写英文字母字符串为处理对象；不把 null 当作合法输入。实现也兼容空串。

考查点

这道题不是比较当前位置是否相等，而是比较两个前缀的最优答案。

  • 用二维数组保存已解决的前缀问题，避免反复枚举删除方案。
  • 把“前 i 个字符”和 Java 下标 i - 1 区分开。
  • 解释为什么字符不相等时，要保留跳过任意一边的选择，而不是把状态清零。

把不相等的状态设成 0，算的是另一类要求连续的匹配问题，不是本题。

Java 代码

class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length();
        int n = text2.length();
        // dp[i][j]：两个字符串分别取前 i、j 个字符时的答案。
        int[][] dp = new int[m + 1][n + 1];

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[m][n];
    }
}

文字推导与正确性

先把空前缀留出来

定义 dp[i][j] 为 text1[0..i) 和 text2[0..j) 的最长公共子序列长度。

只要有一边是空串，就不可能留下公共字符，因此 dp[0][j] 和 dp[i][0] 都是 0。数组多开的一行一列，存的正是这些有意义的边界，而不是单纯为了避免越界。

两个末尾字符相等：为什么直接接上去？

设末尾字符都是 c。去掉这两个末尾后，已有的最优公共子序列一定可以接上一个 c，所以至少能得到 dp[i - 1][j - 1] + 1。

反过来，取当前前缀的任意一个最优公共子序列。如果它不以 c 结尾，就不会使用这两个末尾位置，可以整个放进较短的两个前缀；如果它以 c 结尾，删掉最后一个字符后，剩余部分也一定能放进较短的两个前缀。因此，长度不会超过左上角答案加一。

上下界一致，于是：

dp[i][j] = dp[i - 1][j - 1] + 1。

两个末尾字符不同：为什么只需要两个方向？

它们不能同时成为同一个公共子序列所用的末尾位置，因此任何合法匹配都至少没有使用其中一个末尾。

  • 不用 text1 的末尾，问题落到 dp[i - 1][j]。
  • 不用 text2 的末尾，问题落到 dp[i][j - 1]。

取二者最大值就覆盖了所有方案。两边都不用也已被覆盖，无需另加一种情况。

按什么顺序填表？

每个状态只依赖上方、左方、左上方。代码从第一行向下、每行从左向右填，读取的状态都已经求出。

例如 "abc" 与 "ac"：处理到 b 与 c 时不匹配，但上一个前缀匹配到的 a 不会消失；继续处理 c 与 c，就在较短前缀的答案 1 上加一，得到 2。

边界正确、每次转移既能构造合法解又不会漏掉更优解，因此最终 dp[m][n] 就是答案。

复杂度和边界

设两个字符串长度分别为 m、n。非空输入的时间复杂度为 O(mn)，空间复杂度为 O(mn)；精确到空串边界，数组大小是 (m + 1)(n + 1)，初始化也计入开销。

  • 重复字符："aaaa" 与 "aa" 返回 2。每次从左上角接一个字符，不会把同一个位置重复使用。
  • 顺序相反："abc" 与 "cba" 返回 1，不能排序后再求解。
  • 完全不相交：所有状态保持 0。
  • 空串：内层或外层循环不执行，返回对应边界的 0。
  • 数值范围：答案不超过 min(m, n)，题目规模下 int 足够；代码没有数值乘法。不能据此认为任意巨大输入都适用，二维数组首先受内存限制。

若面试官追问空间优化，可以用一维数组，并单独保存更新前的左上角值。先写对二维版，再谈压缩；直接覆盖数组却忘了保存旧状态，会改变转移含义。

面试时忘记怎么办

先在纸上写出一句定义：“dp[i][j] 是两个前缀的答案。”不要从背公式开始。

然后拿 "ab" 与 "ac" 问自己：末尾不相等，是不是必须扔掉一个？分别扔掉之后，正好得到上方和左方两个子问题。

再拿 "ab" 与 "ab" 检查相等分支：末尾两个 b 可以一起保留，前面的部分交给左上角。

最后补上空前缀为零，以及两个循环的填表顺序。如果仍不确定是否误写成子串，手算 "abcde" 与 "ace"：跳过 b、d 后，已有匹配不能归零。

一句话总结

最长公共子序列的状态保存的是两个前缀能留下多少字符：末尾相同接左上，末尾不同在跳过一边的两条路里选更长的。

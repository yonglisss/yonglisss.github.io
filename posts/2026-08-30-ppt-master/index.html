AI 做 PPT 的常见问题，不是“生成不了”，而是生成物只有图片和文本框：图表改不了数据，版式难以复用，交付前仍要重做。PPT Master 是一个开源 Agent Skill，可把 PDF、DOCX、网页或文字材料整理成原生 .pptx。它近期发布 v5.1.0，重点继续落在文字溢出检查、原生图表与预览一致性，以及已有 PPT 的往返编辑上。

📌 这个项目是干什么的

  • 在 Claude Code、Codex、Cursor 等具备读写文件和执行命令能力的 Agent 中运行。
  • 先分析材料与叙事结构，再生成 SVG，最后转换为可编辑的 PowerPoint DrawingML 对象。
  • 支持原生形状、连接线、表格、数据图表、演讲者备注、转场和可选动画，而不是把整页压成图片。
  • 既能从零生成，也能导入已有 .pptx，选择、重排或修改页面；未修改页面可保持原样传递。

🔍 为什么值得关注

更值得关注的不是“又一个一键做 PPT”，而是它把交付后的修改成本当成核心问题。标题、形状和图表仍是 PowerPoint 对象，用户可以继续改文案、颜色与数据。对于要反复评审的汇报材料，这比一次生成的视觉效果更有价值。

项目也提供了较完整的工程化质量控制：检查文字边界、对象越界和原生图表与 SVG 预览的差异；在线示例库同时提供浏览器预览与 .pptx 下载，方便先检查真实产物再决定是否安装。v5.1.0 还把“填充旧 PPT”和“增强旧 PPT”合并为 Edit Native PPTX 工作流，降低了路线选择成本。

🧪 谁适合试，怎么开始

它适合经常制作产品方案、咨询报告、研究汇报的开发者和内容团队，尤其适合已有 AI 编码工具工作流的人。最短尝试路径是安装 Skill：

npx skills add hugohe3/ppt-master

项目要求 Python 3.10 以上；安装 Skill 后还需在对应目录执行 pip install -r requirements.txt。建议先下载官方示例中的 .pptx，确认原生编辑效果；再拿一份 5 页左右、事实已整理好的材料测试，而不是一开始就生成几十页正式汇报。

⚠️ 使用提醒

PPT Master 是工作流，不包含模型能力。生成质量、耗时和成本仍取决于所用模型、上下文长度及图片服务；项目也明确不承诺“一次生成即可交付”。材料会在本机处理，但调用外部模型或图片 API 时，相关内容仍会离开本机。团队使用前应先检查敏感数据策略，并人工复核数字、引用、图表数据和版权。项目采用 MIT 许可证，当前稳定版为 v5.1.0。

二叉树最大路径和：向上只交一条路，答案可以接两边

题意和示例

给定一棵非空二叉树，选一条由相邻节点连接起来的路径，返回节点值之和的最大值。路径至少包含一个节点，不能重复经过节点，也不必经过根节点。

例如，根节点是 -10，左孩子为 9，右孩子为 20，而 20 的左右孩子分别是 15 和 7。最优路径是 15 → 20 → 7，和为 42；强行经过根节点反而会变差。

再看只有一个节点 -3 的树：答案必须是 -3，不是 0。不选任何节点不算路径。

原题：LeetCode 124：Binary Tree Maximum Path Sum。

考查点

  • 后序遍历：先得到孩子的信息，再处理父节点。
  • 状态设计：交给父节点的路径，与已经完成的候选答案不是同一个状态。
  • 路径合法性：一条路不能分叉，不能在连接父节点后还同时保留左右两支。
  • 负数处理：可以放弃负收益的子路径，但不能把整条非空路径也放弃。

Java 代码

TreeNode 使用题目提供的定义，包含 int val、left 和 right。输入按题意保证非空。

class Solution {
    private int answer;

    public int maxPathSum(TreeNode root) {
        // 同一个 Solution 实例多次调用，也应从头计算。
        answer = Integer.MIN_VALUE;
        gain(root);
        return answer;
    }

    // 从 node 开始，向下走一条不分叉路径的最大和。
    private int gain(TreeNode node) {
        if (node == null) {
            return 0;
        }

        int left = Math.max(0, gain(node.left));
        int right = Math.max(0, gain(node.right));

        // 这条路径在当前节点闭合，不再向父节点延伸。
        answer = Math.max(answer, node.val + left + right);

        // 交给父节点的部分只能保留一个方向。
        return node.val + Math.max(left, right);
    }
}

文字推导与正确性

先问：父节点到底能接走什么？

假设当前节点值为 20，左右两边分别能贡献 15 和 7。如果把 15 + 20 + 7 整体交给父节点，父节点再接一条边，20 就会连接三个方向。这不再是一条路径，而是分叉。

因此，递归返回值只能是：必须包含当前节点、从当前节点向下延伸的最大单链和。

先将孩子贡献与 0 比较，分别记为 left、right。返回值就是 node.val + max(left, right)。选择 0 表示不接这个孩子，不表示删掉当前节点。

再问：什么时候可以同时用两边？

当路径不再向父节点延伸时，可以在当前节点把左右两条单链接起来。候选答案为 node.val + left + right。

上面的示例中，节点 20 用 15 + 20 + 7 = 42 更新答案，却只向根节点交出 20 + 15 = 35。根节点随后算出的候选和为 -10 + 9 + 35 = 34，不会覆盖已经找到的 42。

为什么不会漏掉最优路径？

树中任意一条非空路径都有唯一的最高节点，也就是路径上最靠近根的节点。以它为界，路径至多向左、向右各延伸一条单链，也可能只包含它自己。

后序遍历处理这个最高节点时，两个孩子已经提供了各自最好的单链。负贡献不接，正贡献接上，得到的就是以该节点为最高点的最佳路径。每个节点都做一次这样的比较，因此所有可能的最高点都被覆盖。

这也解释了为什么只需一个返回值和一个全局答案：返回值保证可连接，全局答案保存已经完成的路径。

复杂度和边界

  • 时间复杂度 O(n)：每个节点访问一次，只做常数次比较与加法。
  • 额外空间 O(h)：来自递归调用栈；平衡树为 O(log n)，链状树最坏为 O(n)。
  • 全负数：answer 必须从最小整数开始。两边贡献都被截为 0 后，仍会比较每个节点本身，最终选中最大的负数。
  • 单节点、零值、重复值：无需额外分支。节点值相同不代表节点重复，路径合法性取决于连接关系。
  • 多次调用：在公开方法内重置 answer，避免继承上一次的最大值。
  • 数值范围：此处沿用原题的 int 解法；迁移到自定义数据时，必须确认整条路径和不溢出。若不能保证，应把贡献、候选值、答案及返回类型一并改为 long。
  • 深树：递归写法可能在极深的链状树上触发 Java 栈溢出。若环境要求支持这类输入，应改成显式栈的后序遍历；不能因为复杂度是 O(n) 就认为调用栈一定安全。

面试时忘记怎么办

先画三个节点：父节点、当前节点、当前节点的两个孩子。问自己：“如果两个孩子都带给父节点，当前节点会不会连出三个方向？”这能迅速找回单链返回值的定义。

然后在纸上只写两行：

  • 向上交付：当前值加左右贡献的较大者。
  • 更新答案：当前值加左右两份非负贡献。

最后拿单节点 -3 检查初始化，再拿 15 → 20 → 7 检查是否允许答案不经过根。补充后序遍历、O(n) 时间与 O(h) 栈空间，整个解释就完整了。

一句话总结

递归向上交一条能继续接的单链，全局答案才有资格在当前节点连接左右两边。

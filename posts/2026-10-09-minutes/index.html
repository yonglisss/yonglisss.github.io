会议结束后，录音、纪要和待办常散落在不同工具里。Minutes 是一款开源对话记忆工具：在设备本地录制和转写会议、通话或语音备忘，并把记录保存为自己拥有的 Markdown 文件，再通过 MCP 交给 Claude Code、Codex、Cursor 等客户端检索。它近期发布了 v0.28.2，值得关注的不是又一个会议总结器，而是把“本地资料”接进日常 AI 工作流的方式。

📌 这个项目是干什么的

  • 定位：本地优先的录音、转写和会议记忆应用，支持桌面端、命令行及 MCP 服务。
  • 适合谁：常开会议、需要回查决策或行动项，并希望让编码助手读取自己会议记录的个人与团队。
  • 数据组织：转写内容保存为 ~/meetings/ 下的 Markdown 文件；MCP 客户端可搜索用户选择开放的历史记录。
  • 项目状态：MIT 许可证；GitHub 最新 Release 为 v0.28.2（2026 年 10 月 8 日）。

🔍 为什么值得关注

  1. 记录与模型调用分开。 采集、转写和存储在本机进行，文件格式可读、可迁移。你可以把它理解为给 AI 助手准备一份可搜索的个人会议档案，而不是把记忆锁在某个 SaaS 里。
  2. 用 MCP 连接现有客户端。 Minutes 提供标准 MCP 服务，客户端可搜索会议、读取具体记录。比如回问“上个月关于计费的决定后来改了吗”，比只看单场会议摘要更接近真实工作中的追溯需求。
  3. 上手路径很短。 README 提供样例会议数据，不必先开麦或安排真实会议，就能接入 MCP 并验证跨会议检索是否适合自己的工作流。

🧪 谁适合试，怎么开始

  • 如果你已经在用 Claude Code、Codex、Cursor 或其他 MCP 客户端，且会议记录常需要回查，可以先从样例开始。
  • macOS 可按官方说明通过 Homebrew 安装桌面端：brew install --cask silverstein/tap/minutes。再安装 MCP 服务并加载样例：claude mcp add minutes -- npx -y minutes-mcp、minutes demo --full。随后向客户端提一个需要跨会议核对的问题。
  • 桌面端包含命令行；也可按官方安装文档选择 CLI。Windows 用户需使用 Release 提供的 zip 包，Linux 支持情况和所需能力应先核对安装文档，不要直接套用 macOS 命令。

⚠️ 使用提醒

  • “本地优先”不等于任何信息都不会外发：若让云端 AI 助手或摘要服务处理会议内容，被授权的上下文会发送给对应服务商。配置前先确认客户端的模型与数据策略。
  • 会议录音涉及参会者知情与同意。项目提供披露提醒辅助，但不替代法律判断；实际使用前应遵守所在地区和组织要求。
  • 先用样例验证检索效果，再决定是否用于重要会议。识别质量、设备兼容性和不同平台安装细节，应以自己的环境实测为准。

二分答案 · 边界查找 · Java

x 的平方根：二分不是找相等，而是找最后一个可行值

题意：不需要算出小数

给定非负整数 x，返回平方根向下取整的结果，不借助内置开方或幂函数完成计算。

例如 x = 8，答案是 2。这里不是四舍五入：虽然真实平方根更接近 3，但 3 × 3 已经超过了 8。

换成便于判断的条件：寻找最大的整数 k，使 k² ≤ x。这句话比“求平方根”更容易转成程序。

考查重点

  • 能否把计算问题转成单调边界查找。
  • 能否解释可行时为什么还要向右搜索。
  • 能否写出收缩区间的规则，避免死循环。
  • 能否在乘法之前扩展类型，避免整数溢出。

Java 实现

下面使用闭区间 [left, right]，并单独记录已经找到的可行答案。

class Solution {
    public int mySqrt(int x) {
        if (x < 2) {
            return x;
        }
        int left = 1;
        int right = x / 2;
        int answer = 0;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            long square = (long) mid * mid;
            if (square <= x) {
                answer = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return answer;
    }
}

核心思路：可行答案在左边，越界答案在右边

为什么二分的是答案

候选整数从小到大排列时，平方也随之增大。条件 k² ≤ x 的结果只能先成立、后不成立，不会在失败之后又变回成功。

所以我们不必枚举每一个整数，只需要找到这段“成立区间”的右端点。

对于 x ≥ 2，答案落在 [1, x / 2] 中。x = 2 和 3 的答案都是 1；更大的整数也满足这个上界。提前处理 0 和 1，可以让后面的边界保持简单。

满足条件，为什么还不能结束

当 mid² ≤ x 时，mid 只是一个可行答案，不一定是最大的可行答案。

因此先把它保存到 answer，再令 left = mid + 1，尝试更大的值。反过来，如果 mid² > x，那么所有不小于 mid 的整数都不可能成为答案，令 right = mid - 1 即可。

每次都排除已经检查的中点，所以区间会持续缩小。

用 8 走一遍

初始范围是 [1, 4]。

  1. 中点为 2，平方是 4，可行。保存答案 2，继续搜索 [3, 4]。
  2. 中点为 3，平方是 9，超出目标。右边界缩到 2。
  3. 此时左边界是 3、右边界是 2，区间为空。返回保存的答案 2。

为什么不会漏掉正确答案

一次比较后，丢弃的一侧要么已经不可能可行，要么已经被当前保存的可行值覆盖。answer 始终对应一个不超过目标平方值的整数。

区间耗尽时，不再有比 answer 更大的可行候选，所以它就是向下取整后的平方根。

乘法之前转 long，而不是之后

Java 中两个 int 相乘，先按 int 运算，再赋值给 long 并不能挽回已经发生的溢出。

因此需要写成 (long) mid * mid，让乘法本身按 long 进行。中点用 left + (right - left) / 2 计算，也避免直接相加带来的风险。

复杂度与边界案例

对 x ≥ 2，时间复杂度为 O(log x)，额外空间为 O(1)。0 和 1 直接返回。

适合核对的输入包括：0 → 0、1 → 1、2 → 1、4 → 2、8 → 2、9 → 3，以及 2147483647 → 46340。

本次发布在 Python 中执行了相同边界更新规则，并与标准库整数平方根核对；这验证的是算法逻辑，不等同于 Java 编译运行。

面试时忘记怎么办

先不要背二分模板，先把目标说清楚：

我要找最大的 k，使 k² ≤ x。这个条件有单调性，可以二分答案。

接着解释两种动作：可行就保存并向右，不可行就向左。最后补充终止条件、乘法类型和复杂度。

如果担心边界写错，现场拿 x = 2 和 x = 8 走一遍，比笼统地说“应该没有问题”更有说服力。

最值得记住的一句话

二分并不总是在寻找相等的值，也可以寻找最后一个仍然满足条件的值。

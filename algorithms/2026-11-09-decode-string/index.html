字符串解码：用栈保存进入括号前的现场

题意和示例

把形如 k[内容] 的编码展开成字符串：方括号内的内容重复 k 次，内容中也可以继续包含编码。普通字母保留原样，相邻片段顺次连接。

  • 3[a]2[bc] → aaabcbc。
  • 3[a2[c]] → accaccacc。
  • ab12[c]d → abccccccccccccd。

按题目的合法编码前提处理：括号匹配，次数为正整数，数字只表示重复次数，不是待输出的文字。这里不实现非法输入的语法检查，也不把负数、零次数当作需要支持的扩展。

原题：LeetCode 394 · Decode String。

考查点

难点不是重复字符串，而是嵌套时不能丢掉上一层已经处理好的前缀。

  • 栈的后进先出：最后进入的括号，必须最先完成解码。
  • 上下文保存：进入一层时，同时保存前缀和该层重复次数。
  • 多位数字解析：12 要逐位累加，不能读成两次独立操作。
  • 对象生命周期：保存旧构造器后创建新构造器，不能把旧对象清空后继续共用。

Java 代码

用两个 Deque 分别保存次数与前缀；两个栈在同一位置压入、弹出。

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public String decodeString(String s) {
        Deque<Integer> counts = new ArrayDeque<>();
        Deque<StringBuilder> prefixes = new ArrayDeque<>();
        StringBuilder current = new StringBuilder();
        int number = 0;

        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch >= '0' && ch <= '9') {
                number = number * 10 + (ch - '0');
            } else if (ch == '[') {
                counts.push(number);
                prefixes.push(current);
                current = new StringBuilder();
                number = 0;
            } else if (ch == ']') {
                int repeat = counts.pop();
                StringBuilder previous = prefixes.pop();
                for (int j = 0; j < repeat; j++) {
                    previous.append(current);
                }
                current = previous;
            } else {
                current.append(ch);
            }
        }
        return current.toString();
    }
}

文字推导与正确性

从一个括号边界确定状态

扫描 ab3[c2[d]]e，读到第一个 [ 时，手里有前缀 ab 和次数 3。它们属于外层，不能混进内层的内容。因此把两者压栈，让新的 current 从空串开始。

读到第二个 [ 时，保存的是内层前缀 c 和次数 2。随后读入 d，第一个 ] 将它展开并接回 c，得到 cdd；第二个 ] 再把 cdd 重复三遍接回 ab。最后追加 e。

每个右括号只做一件事：把已经完成的这一层，归还给等待它的上一层。

四种字符对应四种动作

数字只更新 number = number * 10 + digit。左括号保存现场，并同时清零次数、切换到新的空构造器。字母直接追加。右括号弹出现场，完成“前缀 + 当前串重复若干次”，再让结果成为当前串。

注意，进入新层时使用 new StringBuilder()，不是对 current 调用 setLength(0)。栈里保存的是对象引用，清空原对象会连带破坏已保存的前缀。

为什么不会漏掉或串错层级

保持这样的不变式：current 始终是当前层已扫描部分的解码结果；栈中每一对元素，记录一个尚未闭合的外层前缀和重复次数。

字母追加和数字累加不破坏这个关系。左括号把当前层暂停，建立一个空的内层；右括号出现时，内层结果已经完整，栈顶又恰好是最近暂停的外层，按规则合并即可恢复不变式。

合法输入结束时所有括号都已闭合，栈为空，current 就是完整答案。

复杂度和边界

令输入长度为 n，输出长度为 L，最大嵌套深度为 d。

  • 时间：更准确地说是 O(n + C)，其中 C 是所有闭括号展开时累计复制的字符数；保守上界为 O(n + dL)。这个逐层构造的版本不能无条件声称 O(n + L)，因为 1[1[...长字符串...]] 也会在每层重复复制同一批字符。
  • 空间：O(L + d)，计入构造中的字符串、栈和最终返回值。不能只按编码长度估算空间，短编码也可能生成很长的结果。

需要单独检查这些情况：

  • abc：没有括号，直接返回字母串。
  • 10[a]：次数跨多位，进入括号后必须重置数字。
  • 2[a]3[b]：相邻编码互不干扰。
  • 2[a2[b]]：先完成内层，不能提前重复外层。
  • 1[1[abc]]：重复一次也要正确恢复上下文。

重复字母不需要去重。实现使用 int 解析次数，依赖题目对重复次数的范围保证；若改成处理任意外部输入的服务，需要加数值溢出、最大输出长度和非法编码检查，不能直接沿用题目中的信任前提。

面试时忘记怎么办

先写下 x2[a3[b]]，问自己：进入内层以后，外面的 x、2 和 a、3 放在哪里？只要看见“先暂停，后恢复”，就能从调用栈类比到显式栈。

接着说清三个变量：当前层结果、尚未消费的次数、保存外层现场的栈。先写 [ 和 ] 的处理，再补普通字符与多位数字。

最后用 12[a] 查数字累加，用 2[a2[b]] 查层级恢复，并说明复杂度包含逐层字符串复制，而不是只看输入扫描了一遍。

一句话总结

遇到左括号保存现场，遇到右括号把完整内层接回现场；栈里存的是等待恢复的上下文。

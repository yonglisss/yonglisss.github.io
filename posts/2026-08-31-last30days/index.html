搜索一个新工具时，普通网页结果常被旧文章和 SEO 内容占满，真正有用的体验却散落在 Reddit 评论、Hacker News 讨论、YouTube 字幕和 GitHub Issue 里。last30days 是一个开源 Agent Skill：它并行检索近期社区信号，按相关性、互动和新鲜度整理，再让 Agent 综合成带来源的研究简报。项目今日进入 GitHub Trending，单日新增约 271 Star。

📌 这个项目是干什么的

last30days 不是新的搜索网站，而是一套可安装到 Claude Code、Codex、Cursor、Gemini CLI 等 Agent 宿主的研究工作流。输入人物、产品、公司或技术主题后，它会查询 Reddit、Hacker News、Polymarket、GitHub 与网页；配置密钥或本地工具后，还可扩展到 X、YouTube、TikTok、arXiv、Techmeme 等来源。

它保留帖子、评论、字幕、互动数据和链接，并把同一事件的跨平台材料合并，适合做工具选型、用户需求研究、会前准备和热点追踪。

🔍 为什么值得关注

更值得关注的是“来源覆盖可诊断”。不同平台经常遇到缺少密钥、Cookie 失效、限流或接口变化，项目提供 doctor 健康检查，并在结果中区分无结果与抓取失败，避免把“没搜到”误写成“没人讨论”。

其次，它把近期社区内容当作补充证据，而不是替代事实。GitHub Release、网页资料与社交讨论可以交叉查看，读者既能看到官方变化，也能了解真实使用反馈。当前 v3.21.1 还将 Perplexity Sonar 接入迁移到 Agent API，项目仍在持续更新。

🧪 谁适合试，怎么开始

它适合需要高频追踪 AI 工具、竞品反馈或技术社区动态的开发者、产品经理和内容团队。最短路径是安装 Skill：

npx skills add mvanhorn/last30days-skill -g

Reddit、Hacker News、Polymarket 和 GitHub 可零配置起步。建议先研究一个自己熟悉的项目，用官方 Release 和已知事件核对结果；确认引用、时间范围和来源状态可靠后，再配置 X、YouTube 等需要 Cookie、CLI 或 API Key 的来源。

⚠️ 使用提醒

互动量不等于事实，也可能受热门账号、平台人群和抓取覆盖影响。涉及价格、安全、法律、医疗或公司决策时，仍要回到官方文档和原始材料复核。项目会处理浏览器会话与第三方 API 凭据，安装前应审查脚本和权限，优先使用隔离环境与最小权限密钥。项目采用 MIT 许可证，运行要求包含 Python 3.12+ 和 Node.js；部分来源可能产生 API 费用。

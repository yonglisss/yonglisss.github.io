二叉树的最大深度：先说清递归返回什么

题意和示例

给定二叉树的根节点 root，返回从根走到最远叶子时，路径上共有多少个节点。这里数的是节点，不是边；只有根节点的树，答案是 1。

例如，层序表示 root = [3,9,20,null,null,15,7] 的树中，根节点是 3，左右孩子是 9 和 20，20 的孩子是 15 和 7。最长路径可以是 3 → 20 → 15，因此返回 3。

[1,null,2] 返回 2，空树 [] 返回 0。这些数组只是树的表示方式，函数接收的仍是节点对象。

题目约束为节点数不超过 10^4，节点值在 [-100,100] 之间。节点可以重值，树也不保证平衡。

原题：LeetCode 104：二叉树的最大深度。

考查点

  • 函数契约：maxDepth(node) 返回以 node 为根的子树深度，不是从整棵树根走到该节点的距离。
  • 结果组合：左右分支只能选一条继续走，因此取较大值，而不是把两边相加。
  • 终止条件：空树深度为 0，叶子的深度就自然得到 1。
  • 资源边界：节点总数决定访问量，树高决定递归调用栈有多深。

Java代码

TreeNode 使用题目提供的定义，包含 int val、TreeNode left 和 TreeNode right。不需要全局变量，也不需要传入当前层数。

class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) {
            return 0;
        }

        int leftDepth = maxDepth(root.left);
        int rightDepth = maxDepth(root.right);
        return 1 + Math.max(leftDepth, rightDepth);
    }
}

这是递归解法；对于接近一万层的链状树，Java调用栈可能不足，不能把数学上的正确性等同于任意运行环境都不会栈溢出。深树场景可改用下面的非递归实现。

import java.util.ArrayDeque;
import java.util.Queue;

class IterativeSolution {
    public int maxDepth(TreeNode root) {
        if (root == null) {
            return 0;
        }

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        int depth = 0;
        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
            depth++;
        }
        return depth;
    }
}

在判题平台采用后一版本时，把类名改为平台要求的 Solution。固定本层的 levelSize 后再入队下一层，否则会把不同层混在一起。

文字推导与正确性

先定义返回值，再写递推式

把以某节点为根的子树深度记为 D(node)。如果节点不存在，没有节点可数，所以 D(null) = 0。

如果节点存在，从它出发的最长路径，要么进入左子树，要么进入右子树。两条路径不能同时走，因此：

D(node) = 1 + max(D(node.left), D(node.right))

这个 1 只负责当前节点。递归函数返回的子树深度已经包含孩子，不要再为孩子额外加一。

用例子追一次返回过程

在示例中，15 和 7 都是叶子，各自返回 1 + max(0,0) = 1。节点 20 收到两个 1，返回 2；节点 9 返回 1。根节点最终返回 1 + max(1,2) = 3。

计算从根向下发起，答案却在子调用完成后向上合成。这是后序处理的含义，不需要额外保存遍历序列。

为什么对任意二叉树都成立

空树返回 0，与定义一致。假设左右子树的调用都返回了正确深度，那么经过当前节点的最长向下路径，必然选择更深的那棵子树，并额外包含当前节点。递推式因此给出正确结果。沿着树从空子树逐层向上，这个结论覆盖整棵树。

层序版本使用另一条不变量：每轮开始时，队列恰好保存当前层的全部节点。处理固定数量的节点后，队列只剩下一层，depth 增加一次。队列清空时，所有层恰好数完。

复杂度和边界

递归版本每个非空节点访问一次，空指针检查总量也是线性的，时间为 O(n)。同时存在的调用对应一条根到叶路径，辅助空间为 O(h)，其中 h 是树高。平衡树的栈深为 O(log n)，链状树则退化为 O(n)。

层序版本时间同样为 O(n)，队列空间为 O(w)，w 是最大层宽；队列可能短暂混有相邻两层，但规模仍为 O(w)。它避免深递归，却不是常数空间方案。

需要主动核对这些边界：

  • 空树与单节点：分别返回 0、1，不要把深度按边数计算。
  • 只有一侧孩子：空的一侧返回 0，仍选择非空一侧；这里求最大深度，不是最小深度。
  • 负数与重复值：代码不读取 val，答案只受树形影响，不需要排序或去重。
  • 极深或极宽：深树关注递归栈，宽树关注队列内存。ArrayDeque 不接收 null，所以必须先判断孩子是否存在。
  • 整数范围：深度不会超过节点数，在本题约束下 int 足够；不累加节点值，不存在节点值求和溢出。

面试时忘记怎么办

先拿只有一个节点的树验算：“答案应该是1，说明空子树应该贡献0。”这能同时确定计数单位和终止条件。

再把问题缩小：“假设左右子树的深度已经知道，我只需选较大值，再算上当前节点。”不要先纠结整棵树的遍历顺序，先把当前层需要的信息讲清楚。

最后补上资源取舍：“递归每个节点访问一次，栈空间随树高增长；如果输入可能是一条很长的链，我会用队列按层计数，避免调用栈溢出。”

如果临场记不住公式，就用“空树0、叶子1、单链2”这三个结果反推。若公式在左右深度都是1时给出3，就说明误把两条分支加在了一起。

一句话总结

先约定函数返回子树深度，再用“较深的孩子加当前节点”组合答案；树很深时，把递归栈换成显式层序队列。
